# Тестовое задание: Playable Ad (Spot the Difference)

**Ссылка на рабочий прототип:** https://gusigus.github.io/PlayableAdAzurtest/ (Для теста изменения экрана нужно запрустить эмуляцию дейвайса через F12 и перезагрузить страничку)

Проект выполнен в рамках тестового задания для **Azur Games**. 

Основной упор при разработке был сделан на экстремальную оптимизацию веса проекта, производительность, безупречную адаптивность UI и поддержание строгой, интуитивно понятной иерархии сцены и файловой системы.

## 🛠 Технические характеристики
* **Версия Unity:** 2021.3.27 (согласно ТЗ)
* **Интеграция анимаций:** Spine 2D Runtime 3.8 (Custom Cleaned)
* **Размер итогового WebGL билда:** ~4.57 MB (С учетом компрессии. Что бы выложить проект на github pages пришлось выключить компрессии)
* **Целевые платформы:** WebGL 

## 🚀 Ключевые архитектурные решения

### 1. Адаптивная верстка (Responsive Layout)
Проект нативно поддерживает как вертикальную (Portrait), так и горизонтальную (Landscape) ориентации без обрезки ключевого контента. 
* Реализована система жестко закрепленных хедера и футера (Fixed Header/Footer).
* Игровое поле динамически масштабируется в оставшемся пространстве с помощью `Aspect Ratio Fitter`, гарантируя, что арт не искажается при смене ориентации девайса.
* **Мост Size-to-Scale для Spine:** Поскольку `SkeletonGraphic` (Spine) генерирует 2D-сетку, игнорирующую изменения Width/Height, был написан легковесный адаптер `SpineResponsiveScaler`. Он считывает текущую ширину динамического фона и пропорционально переводит её в физический `Scale` сетки. В связке с точечной настройкой UI-якорей (Anchors), это намертво "приваривает" элементы и анимации к нужным координатам фона, полностью исключая дрифт при переключении ориентации экрана.

### 2. Экстремальная оптимизация (Zero-Bloat)
Чтобы уложиться в жесткие лимиты рекламных сетей (до 5 MB) и добиться размера билда в 4.57 MB, были приняты следующие решения:
* **Spine 1-Draw-Call:** Использован Runtime 3.8, из которого полностью вырезан мусор (папки Examples, тяжелые 3D шейдеры, лишние библиотеки). Графика для `SkeletonGraphic` жестко упакована в единый атлас с обрезкой прозрачности (Whitespace stripping), что позволяет рендерить сложную скелетную анимацию ровно за **1 Draw Call**.
* **UI Particle Burst:** Вместо использования встроенной системы частиц Unity Particle System (добавляющей лишние шейдеры и вес), эффекты клика и разлетающихся искр написаны математически через корутины и UI Images.
* **Органичные корутины (NaturalBlink):** Вместо использования тяжелого окна Animator для таких деталей, как моргание глаз персонажей, написан скрипт `NaturalBlink`. Он симулирует органичное поведение (случайные интервалы, шанс на микродвижения или двойное моргание), экономя память.
* **Procedural Animations:** Туториал (рука) и "пульсации" элементов анимированы процедурно (с использованием `Mathf.Sin` и кастомной математики упругости `ElasticOut`).
* **Таймер на спрайтах:** Отказ от TextMeshPro в пользу горячей замены легковесных спрайтов с цифрами (0-9) для работы таймера.

### 3. Задание со звездочкой (Анимация окружения)
Анимация деталей локации реализована поверх "сплюснутого" (flattened) фона. Это позволило добавить игре динамики, не разбивая весь задник на десятки отдельных слоев, тем самым сохранив минимальное количество Draw Calls. Spine-анимации (птицы, персонажи) и анимированные "наклейки" корректно масштабируются вместе с основным артом при повороте экрана благодаря интеграции в единую иерархию Canvas.

### 4. Эталонная иерархия и структура проекта
Внимание к деталям сохранено не только в коде, но и в организации рабочего пространства:
* Иерархия сцены строго разделена на логические блоки: `UI_Header`, `Game_Board_Layout` и `UI_Footer`. Никаких лишних или пустых объектов.
* Файловая система очищена от вложенных дубликатов и мусора. 
* В репозиторий загружены только необходимые исходники (папки Library, Temp, Logs и кэш исключены).

## 📂 Структура проекта (Assets/)
* `Import/` — Оптимизированные и упакованные атласы (вкл. `.atlas.txt` для корректного чтения в Unity 2021+), спрайты, JSON-скелеты Spine.
* `Prefabs/` — Заготовленные UI-элементы и эффекты.
* `Scenes/` — Основная и единственная сцена Playable Ad.
* `Scripts/` — C# скрипты (Layout-контроллеры, `SpineResponsiveScaler`, логика таймера, процедурные анимации, эффекты).

### 💻 Код: SpineResponsiveScaler.cs
*(Пример кастомного моста для адаптации Spine под Unity UI Aspect Ratio Fitter)*

```csharp
using UnityEngine;

[ExecuteInEditMode]
public class SpineResponsiveScaler : MonoBehaviour
{
    [Header("UI References")]
    public RectTransform referenceBackground; 

    [Header("Settings")]
    public float originalArtWidth = 1080f; 

    void LateUpdate()
    {
        if (referenceBackground != null)
        {
            float ratio = referenceBackground.rect.width / originalArtWidth;
            transform.localScale = new Vector3(ratio, ratio, 1f);
        }
    }
}
```
